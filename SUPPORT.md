# Voice Dictate Support

The native Free/Pro macOS app is being prepared for the Mac App Store and
is not yet available for purchase. This repository also contains a separate
open-source Python preview; please specify which edition you are using.

## Contact

[Open a support issue](https://github.com/pstarwars2026/voice-dictate/issues/new)
or [check existing issues](https://github.com/pstarwars2026/voice-dictate/issues).
Include the app version, macOS version, Mac chip, the error message, and the
steps that led to the problem. Issues are public. Do not attach personal
recordings, transcripts, passwords, purchase receipts, or payment details.

## Native App Requirements

- Apple Silicon Mac running macOS 26.2 or later.
- Internet access for the initial model download, approximately 5.18 GB.
- Free storage for the app, model, temporary downloads, and recordings.
  Keep additional space available while installing a model update.
- Microphone permission for recording. Transcription runs locally once the
  model is installed.

## Recording and Copy

If recording does not start, check the selected microphone and microphone
permission under System Settings > Privacy & Security > Microphone.
Free allows 30 seconds per recording and 5 minutes per UTC day. Restarting
the app does not reset this allowance. The reset may occur at a different
time than local midnight.

Pro has no daily quota and uses a 60-minute recording safety stop. Both
tiers use Copy in this first release; automatic insertion into other apps
is not included. Review the transcript before using it, particularly names,
numbers, or technical language.

## Models

Allow the first model download to finish before recording. If it is
interrupted, retry from the model controls; partially downloaded files can
resume. Check available storage and network access if it fails. Model
updates are compatible revisions selected by the project, not every newly
published model. Cached transcription does not need an internet connection.

## Pro Purchase and Restore

The planned upgrade is a one-time, non-consumable purchase, with a US price
of $2.99. The App Store will display the price for your region when the app
is available. There is no subscription. Pro unlocks longer recordings and
Polished English, Original Language, and Developer modes.

Use Restore Purchases in the app while signed into the Apple Account used
for the original purchase. A pending purchase does not unlock Pro until
Apple approves it. For billing or refund help, use Apple's purchase support.
Do not buy Pro again to troubleshoot a restore problem.

See the [privacy policy](PRIVACY.md) for local storage and network behavior.
